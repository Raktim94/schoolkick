Take attendance in a minute. Keep every correction on the record.

CampusOS is open-source school software. Teachers mark a class from a phone, families see today’s status in any browser, and when someone fixes a mistake the original entry stays visible.

Open the appRun it yourself

What each person gets today

Teachers
Open a class, mark everyone present with one tap, adjust the exceptions, save. A draft survives a dropped connection.
Families
A browser page, no app to install. It shows today’s attendance for each child and the last two weeks, and says when the school corrected an entry.
Registrars
Add learners one by one or import a CSV. The importer checks every row first and saves nothing until the whole file is clean.
Principals and owners
A school overview with today’s attendance, a trend, a class-by-day register, and a short list of things that need attention. Every change is in the audit log.

Corrections never overwrite

Changing a mark needs a reason. The new entry is added next to the old one, with who made it and when. Neither teachers nor administrators can edit or delete past entries, and the database enforces that.

Open source, yours to run

The code is MIT licensed. One Docker Compose file starts the app and its database. It also runs on a home server or NAS through CasaOS.

Read the self-hosting guide or browse the source.

git clone %REPO_URL%.git
cd campusos
docker compose -f deploy/docker-compose.yml up -d
# open http://localhost:8080
