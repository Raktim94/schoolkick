Install it in one command

Pick your system. Every route ends at the same sign-in page, and each box says how far it has been tested.

One command, then open your browser

Downloads the latest release, checks its SHA-256, installs Docker if it is missing, and starts SchoolKick under systemd.

Terminal
$ curl -fsSL https://schoolkick.nodedr.com/install-linux.sh | sudo bash
# then open http://localhost:8480
Download .deb (amd64)Download .deb (arm64)Read the scriptRelease notes
  • Ubuntu 24.04 and Debian 12 or newer, amd64 and arm64, with systemd.
  • Runs in Docker and keeps data in a volume. Settings are in /etc/schoolkick/schoolkick.env.
  • Update by running the command again. sudo apt remove schoolkick keeps your data.

Installed, reinstalled, removed and purged on native amd64 and arm64 runners in CI.

Build and run from source with Compose

Starts the app and PostgreSQL 16 in two containers. Set a database password first.

Terminal
$ git clone https://github.com/Raktim94/schoolkick.git
$ cd schoolkick
$ cp deploy/.env.example deploy/.env   # set POSTGRES_PASSWORD
$ docker compose -f deploy/docker-compose.yml --env-file deploy/.env up -d --build
# then open http://localhost:8080/app/
  • Needs Docker with Compose v2 on Linux, Windows or macOS.
  • Migrations run on start. Set ALLOW_SIGNUP=0 once your school exists.
  • Check health at /readyz.

This is how schoolkick.nodedr.com is built and deployed.

Run it with Node.js and your own PostgreSQL

For development, or when you already run PostgreSQL. The database user must be able to create roles.

Terminal
$ git clone https://github.com/Raktim94/schoolkick.git
$ cd schoolkick
$ npm install && npm run build
$ createdb schoolkick
$ DATABASE_URL=postgres://user:pass@localhost:5432/schoolkick npm start
# then open http://localhost:8080/app/
  • Node.js 22.18 or newer and PostgreSQL 16.
  • Run npm test with TEST_ADMIN_URL set to check your setup.

Run from a fresh clone on Linux; 18 of 18 API tests pass.

Import the Compose file in CasaOS

Choose Install a customized app, then Import, and paste the file. It pulls the published image, so nothing is built on the box.

Terminal
$ curl -fsSL https://raw.githubusercontent.com/Raktim94/schoolkick/main/deploy/docker-compose.casaos.yml
# paste the output into CasaOS, change the database password, then install

Windows through WSL2

Install Ubuntu under WSL2, then use the same one-line installer inside it.

Terminal
$ wsl --install -d Ubuntu
# open Ubuntu from the Start menu, then run:
$ curl -fsSL https://schoolkick.nodedr.com/install-linux.sh | sudo bash
# then open http://localhost:8480 in your Windows browser
  • Needs a current WSL with systemd (the default for recent Ubuntu images).
  • Prefer Docker Desktop? Use the Docker Compose tab in PowerShell.

Not yet tried on Windows. Tell us what you see on the issue tracker.

macOS with Docker Desktop

Install Docker Desktop with Homebrew, then build with Compose.

Terminal
$ brew install --cask docker
$ git clone https://github.com/Raktim94/schoolkick.git && cd schoolkick
$ cp deploy/.env.example deploy/.env   # set POSTGRES_PASSWORD
$ docker compose -f deploy/docker-compose.yml --env-file deploy/.env up -d --build
# then open http://localhost:8080/app/
  • Apple silicon and Intel both work with Docker Desktop.
  • Open Docker Desktop once so it can finish setup.

Not yet tried on macOS.

What each person gets

Built around the school day, in the order it happens.

  1. Teachers mark a class in a minute

    One tap marks everyone present, then change the exceptions and save. A draft survives a dropped connection.

  2. Families need no app

    A browser page shows each child’s status today and the last two weeks, and says when the school corrected an entry.

  3. Corrections never overwrite

    Changing a mark needs a reason. The earlier entry stays visible, and the database refuses edits and deletes.

  4. Registrars import safely

    The CSV check lists every problem by row and saves nothing until the whole file is clean.

  5. Owners see what needs them

    Classes that have not taken attendance, recent corrections, and learners with no guardian linked.

Questions

All questions and answers

Is it free?

Yes. It is MIT licensed and you run it on your own server. There is no paid plan.

Is it ready for real learner data?

Not yet. It has automated tests but no independent security or accessibility audit and no legal review. Read the security page first.

What can it not do yet?

Fees, messaging, password reset by email, timetables and native mobile apps. The roadmap lists the order.

Do families install anything?

No. It is a web page, and it can be added to a phone’s home screen.
