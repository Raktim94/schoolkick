Self-hosting SchoolKick with Docker or CasaOS

One container for the app and one for PostgreSQL. It runs on Linux, Windows (Docker Desktop) and macOS, on x86 and ARM.

Start it

git clone %REPO_URL%.git
cd schoolkick
cp deploy/.env.example deploy/.env      # set a database password and SITE_URL
docker compose -f deploy/docker-compose.yml --env-file deploy/.env up -d

Open http://localhost:3847, choose “Create institution”, and you are the administrator. Migrations run on start. Set ALLOW_SIGNUP=0 once your institution exists to close public sign-up.

Settings

VariablePurpose
DATABASE_URLPostgreSQL connection string. Set by the compose file.
SITE_URLPublic address, used in page metadata and the sitemap. Example: https://school.example.org
ALLOW_SIGNUP1 lets anyone create an institution. 0 closes it.
PORTPort inside the container. Default 3847.

HTTPS and backups

Put a reverse proxy that terminates HTTPS in front of the app, such as Caddy or Nginx, and forward the X-Forwarded-For and X-Forwarded-Proto headers. Session cookies become Secure when the request is HTTPS.

Back up the database with pg_dump. The data volume is named schoolkick-db.

docker compose -f deploy/docker-compose.yml exec db pg_dump -U schoolkick schoolkick > backup.sql

CasaOS

In CasaOS choose Install a customized app, then Import, and paste the contents of deploy/docker-compose.yml. The file carries the CasaOS metadata for name, icon, port and data volume.
