Questions and honest answers

What SchoolKick costs, who owns the data, and where the early release stops.

Is SchoolKick free?

Yes. It is open source under the AGPL-3.0 licence, and a commercial licence is available if you want to modify it without publishing your changes. You run it on your own server, so you pay only for the hardware or hosting you choose. There is no hosted service and no paid plan today.

Who owns the data?

You do. The data lives in a PostgreSQL database on your server. There is no analytics, advertising or outside service in the app. You can export it with pg_dump.

Do families have to install an app?

No. The family view is a web page that works in any current browser. It can also be added to a phone’s home screen as an installable web app. A native Android and iOS wrapper is configured but not built.

Is it ready for a real school?

Not yet. This is an early release. It has had automated tests and manual browser checks, but no independent security audit, penetration test or accessibility audit, and no legal review for any country. Read Security before you put real learner data in it, and check your local rules for children’s data.

What can it do today?

Institutions and roles, learners, guardians and classes, attendance with a kept correction history, a family view, an owner overview, CSV import and an append-only audit log. See Features.

What can it not do yet?

Fees and payments, messaging and notifications, password reset by email, timetable and holidays, reports and exports beyond the CSV import, learning content, grading and QR check-in. See the roadmap.

Can a teacher change or delete an attendance mark?

A teacher can correct a mark, and must give a reason. The earlier entry is kept and shown. Nobody, including the owner, can edit or delete past entries: the database blocks it.

How do I reset a forgotten password?

There is no email in v0.1, so there is no self-service reset. An owner can create accounts but cannot yet reset a password. This is the first item on the roadmap.

What do I need to run it?

Docker, or Node.js 22.18 or newer with PostgreSQL 16. It runs on Linux, Windows and macOS, and the Docker image targets amd64 and arm64 (for example a Raspberry Pi through CasaOS). Only Linux with the Node.js route has been tested. See Get started.

Does it support other languages, time zones and countries?

The interface is in English only today. Each institution has one time zone. Nothing in the data model is specific to one country, but there are no country packs yet.

How is one school’s data kept from another’s?

Every query is scoped to the institution in code, and PostgreSQL row-level security rejects cross-institution access even if a query forgets its filter. A test checks this directly against the database.

How can I help?

Try it and report what breaks, improve the docs, or send a pull request. See Contribute. Please never put real learner data in issues, tests or screenshots.
