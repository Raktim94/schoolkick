Install SchoolKick in about 15 minutes

Docker Compose or plain Node.js, then your first register. Every command on this page can be copied with one click.

Status: early release (v0.1). The Node.js route below was run end to end from a fresh clone. The Docker route has not been built on the machine used to write this page (no Docker daemon was available), so treat it as likely to work, not proven. Tell us what breaks on the issue tracker.

Before you start

  • Docker route: Docker with Compose v2 (Docker Engine on Linux, Docker Desktop on Windows or macOS).
  • Node.js route: Node.js 22.18 or newer, and PostgreSQL 16 where you can create a database and roles.
  • About 15 minutes and a modern browser. Chrome, Edge, Firefox and Safari all work.

Option A: Docker Compose

  1. Get the code

    git clone %REPO_URL%.git
cd schoolkick

  2. Choose a database password

    Copy the example settings and set POSTGRES_PASSWORD to a long random value. Set SITE_URL to the address people will use.

    cp deploy/.env.example deploy/.env
nano deploy/.env

  3. Start it

    The first start builds the image and runs the database migrations.

    docker compose -f deploy/docker-compose.yml --env-file deploy/.env up -d --build

  4. Check it is healthy

    curl http://localhost:3847/readyz
# {"ok":true}

  5. Create your institution

    Open http://localhost:3847/app/, choose Create institution, and enter the school name, your name, email and a password of at least 10 characters. You become the owner. Afterwards set ALLOW_SIGNUP=0 in deploy/.env and run the compose command again so nobody else can create an institution.

Option B: Node.js and PostgreSQL

  1. Install and build

    git clone %REPO_URL%.git
cd schoolkick
npm install
npm run build

  2. Create a database

    The database user needs permission to create roles, because migration 002 creates the unprivileged campusos_app role that row-level security relies on.

    createdb schoolkick

  3. Start the server

    DATABASE_URL=postgres://user:pass@localhost:5432/schoolkick npm start
# {"level":"info","msg":"migrations","applied":["001_core.sql","002_rls.sql"]}
# {"level":"info","msg":"listening","port":3847}

    Open http://localhost:3847/app/ and create your institution as in step 5.

Your first register

  1. Add classes and people

    In Classes create a class. In People add a teacher account and a guardian account. In Learners add learners one by one or open Import from CSV (columns name, external_id, guardian_email). Use Check file before importing: it lists every problem and saves nothing.

  2. Assign and enrol

    Assign the teacher to the class, enrol the learners, and link each learner to a guardian.

  3. Take attendance

    Sign in as the teacher, open the class, tap Mark all unmarked as present (the button shows the count), change the exceptions and save. Changing a saved mark asks for a reason, and the original entry stays visible. Sign in as the guardian to see the family view.

Run the checks yourself

Tests need a PostgreSQL admin URL in TEST_ADMIN_URL.

TEST_ADMIN_URL=postgres://postgres:secret@127.0.0.1:5432/postgres npm test
npm run typecheck
CHROME=/usr/bin/google-chrome npm run e2e   # needs the app running; writes screenshots

Before real learner data

Put it behind HTTPS, set up backups, and read what is and is not covered. There is no password reset by email yet. Check your local rules for children's data. Details: self-hosting guide.
