Contribute to CampusOS

Set up in a few minutes, run the checks, send a small pull request.

CampusOS is small on purpose: one TypeScript server, one React app, one PostgreSQL database. Fixes and improvements that keep it simple, fast and private are welcome. For anything bigger than a small fix, open an issue first so we can agree on the approach.

Please never put real learner data in tests, screenshots or issues. By sending a pull request you agree your work is released under the project’s MIT licence.

Set up

You need Node.js 22.18 or newer and PostgreSQL 16.

git clone %REPO_URL%.git && cd campusos
npm install
DATABASE_URL=postgres://user:pass@localhost:5432/campusos npm run dev:server   # API on :8080
npm run dev:web                                                                # app on :5173/app/

Before you push

export TEST_ADMIN_URL=postgres://postgres:secret@127.0.0.1:5432/postgres
npm run typecheck && npm test
npm run build && npm run e2e   # needs the app running and Chrome

How the code is organised

PathContents
server/srcThe API. kernel.ts is the only way to register a route.
server/migrationsNumbered SQL files. Never edit one that has been applied.
server/testAPI tests that run against a throwaway PostgreSQL database.
web/srcThe React app.
siteThe public pages you are reading, rendered by server/src/site.ts.
deploy, DockerfileDocker Compose and CasaOS metadata.
docsArchitecture, decision records, roadmap, traceability, screenshots.

Rules that matter

  • New routes use k.secure (or k.pub with a reason) so the default-deny test passes.
  • Schema changes go in a new migration.
  • UI changes keep status non-colour-only, keyboard operable, and checked in light, dark and at 375 px. npm run e2e must finish with no console errors.
  • Do not claim compliance, security or readiness that the code and tests do not show.

Where to start

Look for open issues. Good first areas: a confirmed Docker build, translations, accessibility checks with a screen reader, and the password reset slice. Everyone who contributes is listed on the contributors page.
